# Website Bán Quần Áo Online

## Giới thiệu

Đây là dự án Website Bán Quần Áo được xây dựng bằng PHP và MySQL nhằm phục vụ cho bài thi cuối kỳ và 
thực hành phát triển ứng dụng web thương mại điện tử.

Website cho phép khách hàng xem sản phẩm, đăng ký tài khoản, đăng nhập, quản lý giỏ hàng và đặt hàng trực tuyến. 
Hệ thống quản trị hỗ trợ quản lý sản phẩm, danh mục và đơn hàng.

## Công nghệ sử dụng

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* PHP
* MySQL
* XAMPP

## Chức năng khách hàng

* Đăng ký tài khoản
* Đăng nhập / Đăng xuất
* Xem danh sách sản phẩm
* Tìm kiếm sản phẩm
* Xem chi tiết sản phẩm
* Thêm vào giỏ hàng
* Đặt hàng trực tuyến
* Quản lý thông tin cá nhân

## Chức năng quản trị

* Quản lý sản phẩm
* Quản lý danh mục
* Quản lý tài khoản người dùng
* Quản lý đơn hàng
* Cập nhật trạng thái đơn hàng

## Hướng dẫn cài đặt

1. Cài đặt XAMPP.
2. Copy source code vào thư mục:

```text
xampp/htdocs/
```

3. Tạo cơ sở dữ liệu MySQL.
4. Import file cơ sở dữ liệu.
5. Khởi động Apache và MySQL.
6. Truy cập:

```text
http://localhost/Bai_Thi_Cuoi_Ki
```

## Tác giả

* Áp dụng kiến thức lập trình web.
* Xây dựng hệ thống thương mại điện tử cơ bản.
* Thực hành kết nối cơ sở dữ liệu MySQL.
* Nâng cao kỹ năng phát triển ứng dụng PHP.
